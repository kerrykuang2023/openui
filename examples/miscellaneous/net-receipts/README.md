# 渠道净实收

独立的中文财务对账示例。OpenUI Lang 的 ReceiptReport 组件由 React Renderer 渲染，使用本地合成流水，支持按样例、销售渠道和业务月份查询，无需模型密钥。

## 运行与验证

使用 Node.js 22.13 或更高版本，在本目录执行：

```sh
npm ci
npm run dev
```

打开 Vite 输出的本机地址。运行 `npm run verify` 可执行账务用例并构建前端。

## 核对样例

默认净实收为 270 元；将样例切换为“第二笔退款处理中”，应为 290 元。选择“跨月全额退款”、线上渠道，10 月为 20 元，11 月为 −20 元，全部期间为 0 元。展开完整流水可检查原订单、退款状态和退款途径。

`ledger.js` 分别累加支付与退款，按原订单销售渠道归集，金额单位为分。`src.jsx` 注册 OpenUI 组件并提供筛选器和样例数据。扩展样例时可在 `ledger.test.js` 添加对账预期。
